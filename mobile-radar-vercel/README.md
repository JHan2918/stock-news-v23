# Market Radar Mobile Vercel

This folder is the new Vercel/Supabase migration target for the mobile Market Radar app.

The existing Render app in `mobile-radar/` remains the production-safe version while this folder is developed and tested.

## Current Goal

1. Keep the Render mobile app running.
2. Deploy a minimal Vercel app from this folder.
3. Move member, session, watchlist, and stock analysis cache data to Supabase/PostgreSQL.
4. Continue reading the shared report DB generated by the local automation:

```text

```
